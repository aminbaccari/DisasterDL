Notes:

- RC: Text layer is nearly empty (bullets only). Provenance is checked against OCR of the page images.
- FALC: Pages 8 and 10 are government posters stored as images. Provenance for them is checked against OCR.
- P2055: Written for building safety evaluators and officials. Page numbers below are PDF page numbers.
- P2055-2: Earthquake focus. Page numbers below are PDF page numbers.
- V1013: Two-page flyer. The copy on ready.gov carries the number V-1013 and the date May 2018, not P-2143 (August 2023), so it is cited as V-1013. Page numbers are PDF page numbers. URL: https://www.ready.gov/sites/default/files/2021-01/ready_wildfire_info-sheet.pdf, retrieved 2026-10-16.
- MTE: Web page, main text saved to a text file. Official government campaign page. Treated as one page (page 1). URL: https://www.ecologie.gouv.fr/feux-foret-et-vegetation, retrieved 2026-10-16.
- ONPC: News report, not official guidance. The original ONPC communique was not found. The article carries a reproduction-rights notice, so entries paraphrase it and quote only short phrases. It is the only Tunisian source and the only source of the number 198. URL: https://fr.allafrica.com/stories/202607090542.html, retrieved 2026-10-16.
